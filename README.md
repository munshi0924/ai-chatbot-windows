# AI Chatbot for Windows

A desktop chatbot application built with Python and OpenAI's API. Supports multiple GPT models including GPT-5.6 Sol, Terra, and Luna.

## Features
- Real-time streaming responses
- Switch between 6 AI models mid-conversation
- Modern dark/light UI with CustomTkinter
- Packaged as a standalone `.exe`

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/ai-chatbot-windows.git
cd ai-chatbot-windows
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
